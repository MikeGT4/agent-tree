# Agent Tree Anleitung

Agent Tree zeigt deine Agenten als lebenden Baum neben dem Chat.

## Was du siehst

![Baum](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-de-1.png)

Hauptsitzung: Modell, Denkstufe, Kontext, Kosten.

Kasten je Unteragent: Aufgabe, aktueller Schritt, Kontext (gelb ab 70 %, rot ab 85 %).

⚠: Warnung, bevor zwei Agenten dieselbe Datei ändern.

## Was du tun kannst

![Aktionszeile](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-de-2.png)

Kasten anklicken, oder ctrl+x tab, Tab, Enter: Stoppen (s), Schreiben, Modell, Denkstufe, Details. Schreiben füllt deine Eingabe, der Agent liest sie beim nächsten Schritt. e: Denkstufe der Hauptsitzung, m: neue Unteragenten, a: Aussehen.

## Tabs

![Berichte](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-de-3.png)

Berichte: Aufgabe und ganze Antwort jedes Agenten.

![Dateien](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-de-4.png)

Dateien: geändert und gelesen je Agent, doppelte oben. Gelesene mit geschätzten Tokens (~).

![Kosten](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-de-5.png)

Kosten: Denkstufe, Tokens, Kosten, Limits.

![Verlauf](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.11/guide-de-6.png)

Verlauf: Ereignisse nach Quelle, Klick auf › zeigt Details.

![Hilfe](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.2/guide-de-7.png)

Hilfe: Tasten, Zeichen, Befehle, Neues.

## Neu

Fenster: deine anderen offenen Terminals, Dateien, die zwei davon ändern, und Markdown zum Prüfen.
