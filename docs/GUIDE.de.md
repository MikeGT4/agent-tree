# Agent Tree Anleitung

Agent Tree zeigt die Agenten deiner Sitzung in Claude Code als lebenden Baum neben dem Chat, mit einem Hebel für jeden.

## Was du siehst

![Baum](https://github.com/MikeGT4/agent-tree/releases/download/v0.6.0/guide-de-1.png)

Hauptsitzung: Modell, Denkstufe, Kontext, Kosten.

Ein Kasten je Unteragent: Aufgabe, was er gerade tut, Kontext (gelb ab 70 %, rot ab 85 %).

![Kästen](https://github.com/MikeGT4/agent-tree/releases/download/v0.6.0/guide-de-2.png)

⚠: Zwei laufende Agenten ändern dieselbe Datei.

## Was du tun kannst

![Aktionszeile](https://github.com/MikeGT4/agent-tree/releases/download/v0.6.0/guide-de-3.png)

Kasten anklicken, oder ctrl+x tab, Tab, Enter: Stoppen (s), Schreiben, Modell, Denkstufe, Details.

Schreiben füllt deine Eingabe. Der Agent liest sie bei seinem nächsten Schritt.

Jeder Eingriff meldet sich in der Zeile.

![Wahl](https://github.com/MikeGT4/agent-tree/releases/download/v0.6.0/guide-de-4.png)

e: Denkstufe der Hauptsitzung · m: neue Unteragenten · a: Aussehen.

## Was es dir bringt

![Details](https://github.com/MikeGT4/agent-tree/releases/download/v0.6.0/guide-de-5.png)

Einen Agenten stoppen statt der ganzen Sitzung.

Einen laufenden Agenten auf ein günstigeres Modell setzen.

Details: gelesene und geänderte Dateien, letzte Nachricht.
