# Agent Tree guide

Agent Tree shows your agents as a live tree beside the chat.

## What you see

![Tree](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-1.png)

Main session: model, effort, context, cost.

One box per sub-agent: task, current step, context (yellow from 70%, red from 85%).

⚠: warns before two agents edit one file.

## What you can do

![Actions](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-2.png)

Clicking a box, or ctrl+x tab, Tab and Enter, opens Stop (s), Write, Model, Effort and Details. Write fills your prompt for the agent's next step. e: main session effort, m: new sub-agents, a: look.

## Tabs

![Reports](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-3.png)

Reports: each agent's task and full answer.

![Files](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-4.png)

Files: changed and read per agent, shared first, tokens estimated (~).

![Cost](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.0/guide-5.png)

Cost: effort, tokens, cost, limits.

![Log](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.11/guide-6.png)

Log: events by source, › for details.

![Help](https://github.com/MikeGT4/agent-tree/releases/download/v0.7.2/guide-7.png)

Help: keys, signs, commands, news.
