# Agent Tree guide

1. In your terminal, then start Claude Code:
   `claude plugin install agent-tree --marketplace MikeGT4/agent-tree`
2. The pane opens by itself with a bonsai (click skips it); `/agent-tree` reopens it, ctrl+x tab focuses it.
3. The main box shows effort, context and cost, sub-agents get boxes, the bottom line your 5-hour and weekly limits.
4. Click a running agent's model (or Tab, Enter): pick an effort, then a model (0 to 4). "Sub-agent model" (m) sets both for sub-agents, the model for new ones, and keeps them.
5. Click an agent's type for its task, latest answer and a message field: click it, type, press Enter to correct it at its next step.
6. ■ on a box stops an agent.
7. a opens the look: style, colors, glow.
8. The advisor box switches your default advisor.
9. `/agent-tree stop` closes the pane, `/agent-tree clear` starts afresh.
